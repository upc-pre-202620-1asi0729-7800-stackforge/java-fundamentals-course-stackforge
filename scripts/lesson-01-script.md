# Guion — Lección 1: ¿Qué es programar y qué es Java? (≈ 6 min)

**Objetivo:** que el estudiante entienda qué es un programa, por qué Java y ejecute su primer "¡Hola, mundo!" sin instalar nada.
**Editor:** OnlineGDB (lenguaje: Java) · **Archivo:** `starter-files/lesson-01-hello-world/Main.java`

## Errores comunes a mostrar
- Olvidar el `;` → mostrar el mensaje de error y cómo leerlo.
- Escribir `system.out` en minúscula: Java distingue mayúsculas y minúsculas.

## Notas de producción
- Fuente del editor al menos 18 px; tema claro para mejor lectura en celular.
